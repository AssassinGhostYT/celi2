# Celisbeth — Galaxia

Una galaxia interactiva en 3D hecha con **Three.js** para Celisbeth: espiral de estrellas, nombre con partículas, corazón que se transforma en oso, cartas que giran y mensajes flotantes.

## Ver la página

**https://assassinghostyt.github.io/celi2/**

## Archivos

| Archivo | Qué contiene |
|---|---|
| `index.html` | Estructura de la página y el `importmap` de Three.js |
| `style.css` | Estilos (fondo negro, canvas a pantalla completa) |
| `script.js` | Toda la escena 3D, animaciones y la interacción con las cartas |

## Controles

- **Arrastra** para girar la cámara 360°.
- **Pellizca / rueda del ratón** para acercar o alejar.
- **Toca una carta** para girarla y leer el mensaje.

## Créditos

Hecho con [Three.js](https://threejs.org/).
